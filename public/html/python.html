datatype

:프로그래밍 언어에서의 데이터의 종류

    종류

  1. int(정수)
  2. float(실수)
  3. string(문자/문자열)=str
  4. bool(진리값)
  5. list(리스트)=[1,2,3,4]
  6. dictionary(딕셔너리) = ('name':'김민수', 'age':'17)
*datatype이 같은 것끼리는 연산 가능
* int + float : 연산가능 / int + str : 연산 불가능 / float + str : 연산 불가능

for x in score: 
    number = number +1 
    if x >= 70:   #만약 x가 70이상이면?
      print("%d번 학생은 합격입니다." %number)    #number이 %d에 들어감
    elif x >=60:     #x가 70보다 작을 때 x가 60보다 크다면?
